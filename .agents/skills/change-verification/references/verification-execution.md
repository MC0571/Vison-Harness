# 验证执行

1. 从 manifest、脚本、Makefile、CI 和维护说明找真实命令，记录运行目录和环境。
2. 固定 commit/head、工作树状态或构件摘要；检查后若候选变化，重新做影响判断。
3. 执行前说明命令及写文件、网络、账号等副作用；权限不覆盖时不运行。
4. 保存退出码、关键 stdout/stderr、生成文件标识和时间相关环境，不只保存“成功”。
5. 失败区分：产品违反判据、测试本身错误、环境不可用、权限不足。修复设置后可重试；随机重跑不可消除失败。
6. 回读构件或外部状态以确认实际结果；响应不明先查询，避免重复创建。

例：`--check` 前后比较 bytes、mtime 和权限，才能支持“只读”；退出码 0 本身不足以证明没有重写。
