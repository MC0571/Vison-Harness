# 有界上下文恢复

## 新会话或旧聊天不可用

从持久事实恢复：当前目录与远端、适用规则、用户指明的工作项、目标/Spec/架构中直接相关部分、当前候选和证据。聊天摘要仅用于定位，不代替关键来源。已有事实足够时停止扩大读取。

## 同名项目与来源冲突

多个同名项目先用绝对路径、远端、组织和候选标识区分。文件与 GitHub 描述不一致时，先判断它们各自承载长期行为还是动态工作事实，再比较对象、版本、范围和时间。旧内容可保留历史效力，不把“更新日期较晚”当作全面覆盖。

例：Spec 描述长期超时行为，Issue 描述本轮只实现持久化。两者不是冲突；本轮范围小于完整行为，但不能把未实现部分改成非目标。

## 持续授权与撤销

持续委托可跨会话复用，但只覆盖相同对象、动作与后果。用户撤销、候选变更、目标仓库变化或从本地写入升级到发布时，旧授权不再覆盖新增部分。授权线索冲突时暂停相关副作用并说明，其他读取和分析继续。

## 截断与不可访问

明确列出已读范围、缺失来源及其局部影响。不能用摘要猜完整正文，也不能把访问失败解释为内容不存在。返回可接手结果时给出准确定位方式，而不是复制一份新的权威状态。
