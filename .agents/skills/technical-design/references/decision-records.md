# 架构与决策记录

当前架构说明“现在长期结构是什么”；方案讨论保存尚未决定的选项；ADR 保存已经作出的重大长期决定及理由。三者不能混用。

只有同时满足以下条件才记录 ADR：存在真实可行权衡；决定已作出；它会长期约束多个后续工作；未来维护者需要理由才能安全改变。局部库选择、可逆实现细节或尚未决定的问题不需要 ADR。

ADR 记录背景、决定、主要替代与后果，不保存负责人、工作状态或审批流程。新决定替代旧决定时保留旧记录历史，在新记录中说明替代关系，并更新当前架构描述。

例：确定所有写入必须经过单一服务以维持一致性，且影响多个功能，可记录 ADR。某个函数使用字典还是列表无需记录。
