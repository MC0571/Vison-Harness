# Agent Instructions

这是项目级 Agent 配置入口，覆盖两类直接工作：AGENTS.md/局部指引维护，以及项目审查规则与宿主 reviewer/sub-agent 入口配置。二者共享相同的长期配置表面和授权边界，不代表每个项目都需要两类文件。

## 执行骨架

1. 确认目标项目、宿主、配置范围和允许修改的文件/设置。
2. 读取根与相关局部指引、既有审查规范、CI/宿主配置及真实命令来源。需要具体分层与审查配置方法时读取[Agent 配置方法](../../../METHOD.md#6-维护-agent-工作约定和审查规则)。
3. 新会话加载、覆盖优先级或组织级事实不清时读取[项目上下文行为约定](../../../specs/project-context/spec.md)；不能从文件名推导宿主一定自动加载。
4. 根文件只放全仓规则，局部文件只放真实差异；已有 Spec/架构规则用引用，不复制。没有局部差异就不创建局部文件。
5. 审查配置先找项目真实缺口：是规则未定义、引用失效，还是宿主没有入口。只有需要时才配置 reviewer/sub-agent；不强制三份规则、三名 Agent 或固定轮次。
6. 只读请求给建议而不写；获准修改时完整读取目标、保留现有安全/审查规则、最小修改并回读。不得为了当前工作通过而自行降低约束。

授权和安全写入见[共享规则](../../../METHOD.md#1-先确认本轮任务和授权)。

结束时区分文件已存在、可手动读取、宿主实际加载和独立判断四种事实。配置完成不等于任何 Spec、代码或 PR 已经审查通过。
