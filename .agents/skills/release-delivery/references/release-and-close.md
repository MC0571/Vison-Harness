# 发布与关闭

## 发布

确认发布对象、版本、许可、目标环境、凭据用途和明确授权。检查版本未倒退/重复，使用项目真实发布命令，并记录实际返回与可回读标识。构建、上传、部署、tag 和 Release 是不同副作用；只执行获准项。

## 关闭

区分本次切片、PR、阶段目标和长期能力。只有对应承诺与必要后置验证都满足，且有关闭授权时才关闭工作项。当前实现困难、PR 合并或部分能力交付都不能静默删除上层目标。

例：PR 合并后还要求安装验证。合并时不自动关闭；安装证据通过并回读后，再在授权内显式关闭。

异常：发布 API 返回超时。先查询版本/tag/构件是否存在及状态；未确认前不重试，避免重复发布。
