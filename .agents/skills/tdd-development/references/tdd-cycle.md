# 行为切片 TDD

## 新增行为

先写一个从公开或稳定入口观察结果的失败检查，确认它因缺少目标行为失败。实现最小切片并重跑；再取下一个可观察切片。不要先堆完所有层再补测试。

## 可复现缺陷

现有稳定失败测试能精确覆盖时直接复用。否则写回归测试重现报告，追踪所有调用者并在共同根因处修复。测试应在修复前失败、修复后通过，并防止同类路径复发。

## 纯重构

先运行能保护现有行为的检查；若保护不足，只补会在重构破坏行为时失败的最小测试。重构期间不改变承诺，完成后重跑同一检查和受影响回归。

每轮红灯都要来自目标行为，而非测试语法、错误夹具或环境。绿灯后才整理结构；重构不能改变失败语义或削弱断言。
