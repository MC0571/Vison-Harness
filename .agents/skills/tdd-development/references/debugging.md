# 调试方法

1. 用准确候选、输入和环境复现；无法复现时记录差异。
2. 缩小输入、调用路径或时间窗口，找到第一次偏离预期的观察点，而不是最后一个错误消息。
3. 提出可证伪原因，写出若原因成立应观察到什么。
4. 每次只改变一个因素，保留原始输出；排除后更新假设。
5. 根因确定后在最小共享位置修复并补回归，检查所有调用者。

偶发故障应固定随机种子、并发条件、时钟或外部响应并收集多次样本，但设置有限预算。不可复现时返回证据和下一判别动作；环境或权限失败单独标记。只读诊断到原因和证据结束，不修改代码。

例：三个调用点都在同一解析器后出现错误，先验证解析器输出；在每个 UI 分别加守卫不是根因修复。
