# 工具与指引发现

## 真实命令

依次检查项目 manifest 的 scripts、Makefile/Taskfile、构建配置、CI 工作流和维护文档，并核对命令适用目录与环境。多个入口存在时说明正式入口与局部快捷入口的差别。没有来源就报告未知，不凭经验编造。

## 规则加载

识别真实宿主，再查它对根/局部指引、优先级和配置位置的现行支持。文件存在、Agent 可手动读取和宿主自动加载分别记录。无法核对宿主行为时，可补通用项目规则，但必须把自动加载标为未验证。

## 最小修改

根规则只保存全仓约定，局部规则只保存差异；已有权威内容用链接或准确定位复用。只缺导航时增加导航，不复制整段方法。Reviewer 配置只有在用户明确需要且格式可从真实宿主资料核对时才创建。

例：CI 调用 `python -m unittest`，README 写的是过期命令。将 CI/当前配置视为可执行入口，并把文档冲突列为局部缺口；未经授权不顺手重写 README。
