# 验证选择

| 证据 | 主要支持 | 不能单独证明 |
| --- | --- | --- |
| 格式/结构 | 可解析、路径和清单一致 | 运行语义或用户效果 |
| 单元 | 局部逻辑与边界 | 跨组件真实交互 |
| 集成 | 组件契约和数据流 | 完整部署/宿主加载 |
| 正式构建入口 | 项目能按支持方式产出 | 安装后行为与产品验收 |
| 安装 | 特定宿主/环境可发现和加载 | 所有宿主与任务效果 |
| 行为场景 | 给定输入下的可观察结果 | 未覆盖输入或长期目标 |

按变化与风险选最小组合：路径解析修改应覆盖编码、越界和符号链接；文案改动通常需要格式与链接；公共协议变化需要单元加集成。外部输入、安全、数据完整性和高影响发布提高强度。

无适用检查时可以 `not-applicable`，但必须说明原因。不能用通过数量抵消未覆盖的核心承诺或授权越界。
