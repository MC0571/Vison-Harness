# 滚动细化

1. 固定现有工作图版本，读取当前批次的承诺、实际完成证据和新决定。
2. 标记仍有效、已完成、等价重复、依赖解除、约束变化和证据缺口；不从状态标签推导功能完成。
3. 保留有效节点与身份，合并等价工作，不清空重建全图。
4. 选择下一批只需满足当前目标、依赖和容量；增加输入、边界、完成条件和集成点，不提前展开远期实现。
5. 说明发生变化的对象、范围和理由。无新事实且已有下一步清楚时返回零修改。

例：底层接口已稳定，只解除两个实现项的“开始阻塞”；发布依赖仍保留，不把整条依赖关系删除。

异常：历史快照和当前工作项描述不同。先比较时间和范围；无法证明完成时标证据缺口，不将节点自动重开或关闭。
