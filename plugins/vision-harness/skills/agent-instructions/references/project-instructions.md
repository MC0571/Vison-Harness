# 项目 Agent 指引

1. 识别真实宿主及其从工作目录向上/向下加载规则的方式；用官方资料或宿主状态核对。
2. 完整读取适用根规则和目标目录已有局部规则，标出重复、冲突和真实缺口。
3. 根文件只写全仓稳定约定：权威事实入口、分支/授权、安全、真实命令和交付要求。
4. 局部文件只写该目录与上级不同的命令、边界或不变量；没有差异不创建。
5. 长期行为、架构和审查标准已有权威源时链接/定位，不复制全文。
6. 修改后回读，并分别验证文件存在、Agent 可读和宿主自动加载。

例：前端目录需要不同测试命令，可用局部规则覆盖命令；全仓“禁止未授权发布”仍由根规则承载，不重复。

异常：宿主不自动读取该文件。可保留为手动入口并明确限制，或在获准且格式已核对时配置入口；不能声称已加载。
