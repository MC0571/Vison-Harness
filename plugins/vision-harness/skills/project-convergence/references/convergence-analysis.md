# 收敛分析

以新事实为起点建立有限链路：它改变哪个目标/工作承载/行为/结构/实现/证据？只读取链路上的对象并固定版本。

分类与判别：

- 目标遗漏：确认能力没有任何承载或被当前切片误删；
- 语义冲突：两个权威约定对同一状态、权限或结果给出不兼容要求；
- 重复规则：同一长期事实被多处手工维护且已出现漂移；
- 架构偏离：实现改变责任、所有权或信任边界而架构仍声称旧结构；
- 失效暂缓承载：Deferred 工作的承载已关闭/替代但能力仍有效；
- 无依据复杂度：流程/抽象不服务确认需求或风险。

指出位置、触发条件、机制和现实影响。文件多、标题不同或风格差异本身不是偏离。

例：旧 Issue 被关闭但其 Deferred 能力仍在愿景中，且没有替代承载；问题是承载失效，不是愿景需要删除。
