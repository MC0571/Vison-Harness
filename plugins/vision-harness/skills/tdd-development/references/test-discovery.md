# 测试入口发现

按项目实际存在的 manifest scripts、Makefile/Taskfile、构建配置、CI 工作流和维护说明定位命令，并核对运行目录、依赖与环境。优先选择最小可判别入口，再按影响扩大。

区分：单元测试验证局部行为；集成测试验证组件交互；构建验证可产出；静态检查验证格式/类型/结构；正式入口验证项目实际支持的命令。它们不能互相冒充。

先运行或读取基线，记录已有失败。目标测试未启动通常是环境/设置失败，不是产品红灯。没有入口时说明缺口，不编造命令、不未经授权引入测试框架；可以用项目现有最小自检支持当前实现。

例：CI 调用 `python3 scripts/test_tool.py`，则优先复用；不要仅因熟悉 pytest 就新增依赖。
