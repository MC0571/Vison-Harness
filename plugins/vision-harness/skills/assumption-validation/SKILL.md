# 关键假设调查

读取[共同规则](../../references/shared-rules.md)和[依赖、行为与审查规则](../../references/engineering-rules.md#4-维护依赖并设计有效的推进方式)。先确认用户要求的是分析、查询还是允许实际试验，以及可使用的环境、数据和副作用。

## 把未知改写成可回答的问题

指出当前哪个决定依赖此假设，以及假设不成立会改变什么。查已有证据及适用版本；不因它来自旧会话就丢弃，也不把不同环境中的成功当作当前成立。

优先处理能推翻职责边界、主要路径或高成本选择的未知。不会影响当前决定的远期细节保留未知身份，不阻塞无关实施。现有事实已足够时直接给结论，不再制造试验。

## 选择最小有效调查

先读取权威文档、实际配置或已有运行记录。需要试验时，明确输入、观察量、环境、有限预算、停止条件以及什么结果支持继续或调整。优先在获准的隔离项目使用非敏感数据，不擅自调用生产资源、付费服务或用户外部账号。

将判断依据写在看到试验结果之前。试验只改变必要变量，记录失败与环境错误；权限不足、网络失败或工具不支持不等于产品路线不可行。模拟只能支持模型内结论，不能冒充真实安装、集成或远端操作。

## 解读与继续

分别列出直接观察、依赖这些观察的推断和剩余未知。区分正常适配成本、需要用户接受的代价、违反已确认边界的根本问题。证据矛盾时比较对象、版本和条件，不按最后一条结果机械覆盖。

达到预算或问题已被回答就停止。结论可以是支持、反驳或尚不确定；说明只影响哪些工作，哪些仍可继续。建议停止一条路线时，指出它承担的有效目标如何保留，不自行删除目标或重写整个规划。

实际记录只写到获准的现有工作载体；临时试验构件按授权保留或清理，不把本地路径当作他人可读取的证据。调查权限不包含实施、合并、发布或接受产品取舍。
